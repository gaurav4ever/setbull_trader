🧠 Proposed High-Level Approach Using One of These Libraries
A. Historical Fetch & DataFrame Build

    At every candle close, query your store for last N candles per stock.

    Build an in-memory DataFrame per stock:

        Rows: last N timestamps (including current)

        Columns: OHLCV and any existing metrics

    Optionally combine all stocks into a larger multi-index DataFrame.

B. Wrap in Strategy Registry

    Define a Strategy interface like Process(df DataFrame) (DataFrame with new columns).

    Strategy registry loops over all registered strategy instances, each receives the DataFrame and returns new result columns.

C. Merge & Store Back

    Merge returned DataFrame columns into your base DataFrame (via Mutate or Join).

    Extract relevant new columns (e.g. only at the current timestamp row) and persist:

        Option 1: mutate the same candle table row

        Option 2: append to a separate strategy_results table

D. Concurrency & Scaling

    Process stocks in parallel using Go routines (e.g. worker pool).

    Use channels to assemble per-stock DataFrames and pipeline them to strategies concurrently.
