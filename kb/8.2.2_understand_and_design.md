# Live Data and Strategy Processing System V2 - Understanding & Design

## Current System Analysis

### Existing Architecture
The current system follows a layered Go architecture with:

1. **Data Layer**: 
   - `stock_candle_data` table stores 1-minute OHLCV data with technical indicators
   - `stock_candle_data_5min` table for aggregated 5-minute data
   - Partitioned by month for performance (3.98M+ rows)

2. **Processing Layer**:
   - `GroupExecutionScheduler` triggers on 5-minute candle closes
   - `OnFiveMinClose` method handles time-based entry types (09:15, 13:00)
   - BB width monitoring for continuous patterns

3. **Strategy Layer**:
   - Python-based backtesting framework with modular processors
   - Entry strategies (1ST_ENTRY, 2_30_ENTRY) with factory pattern
   - DataFrame-based processing with pandas

### Current Data Flow
```
5-min Candle Close → GroupExecutionScheduler → Time-based Triggers → Group Execution → Database Storage
```

## V2 System Requirements

### Core Objective
Build a Go-based V2 system using [Gota DataFrame library](https://github.com/go-gota/gota) that processes live data through multiple strategies in real-time, replacing the current time-based approach with a flexible, data-driven architecture.

### Key V2 Requirements
1. **Event-Driven Processing**: Trigger on every 5-minute candle close
2. **Historical Context**: Fetch N historical candles for each stock group
3. **3D Data Structure**: [stocks][timestamps][columns] format using Gota DataFrames
4. **Strategy Registry**: Modular strategy system with plugin architecture
5. **Column Augmentation**: Strategies add new result columns via Gota Mutate operations
6. **Persistence**: Store augmented data back to database
7. **Configuration-Driven**: All aspects configurable via YAML
8. **Backward Compatibility**: Gradual migration from V1 to V2

## Gota Library Integration

### Why Gota?
- **Native Go**: No CGO dependencies, pure Go implementation
- **Mature**: 3.2k stars, active development, production-ready
- **Rich API**: Filter, Mutate, Join, GroupBy operations
- **Performance**: Optimized for large datasets
- **Type Safety**: Strong typing with Series types (Int, Float, String, Bool)

## Technical Implementation Details

### Gota DataFrame Operations
```go
// Example strategy using Gota
func (s *BBWidthStrategyV2) Process(df *dataframe.DataFrame) (*dataframe.DataFrame, error) {
    // Filter recent candles
    recent := df.Filter(dataframe.F{
        "timestamp", series.Greater, time.Now().Add(-24*time.Hour),
    })
    
    // Calculate BB width using Gota operations
    bbWidth := s.calculateBBWidth(recent)
    
    // Mutate DataFrame with new column
    result := df.Mutate(series.New(bbWidth, series.Float, "bb_width_v2"))
    
    return result, nil
}
```
