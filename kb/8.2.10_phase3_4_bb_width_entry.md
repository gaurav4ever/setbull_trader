# Phase 3.4: BB_WIDTH_ENTRY Strategy Migration

## Overview

Phase 3.4 focuses on migrating the **BB_WIDTH_ENTRY** strategy from Python to Go/Gota. This strategy detects volatility squeeze conditions using Bollinger Bands width analysis and generates entry signals when price breaks out of the squeeze.

## Strategy Analysis

### Python Implementation Analysis

**Source**: `python_strategies/mr_strategy/strategy/entry_strategies/bb_width_entry.py`

#### Core Logic Components:
1. **Bollinger Bands Width Calculation**
   - Calculates BB width as: `BB_Upper - BB_Lower`
   - Tracks lowest BB width from CSV analysis file
   - Uses threshold-based squeeze detection

2. **Squeeze Detection**
   - Detects squeeze when: `current_bb_width <= lowest_bb_width * (1 + threshold)`
   - Default threshold: 20% (0.2)
   - Minimum squeeze duration: 3 candles
   - Maximum squeeze duration: 5 candles

3. **Entry Conditions**
   - **Long Entry**: Price above BB upper band during squeeze
   - **Short Entry**: Price below BB lower band during squeeze
   - Direction bias from configuration

#### Key Parameters:
- `bb_width_threshold`: 0.2 (20% default)
- `bb_period`: 20 (period for BB calculation)
- `bb_std_dev`: 2.0 (standard deviation multiplier)
- `squeeze_duration_min`: 3 (minimum squeeze candles)
- `squeeze_duration_max`: 5 (maximum squeeze candles)

#### State Management:
- `squeeze_detected`: Boolean flag for squeeze state
- `squeeze_start_time`: Timestamp when squeeze started
- `squeeze_candle_count`: Number of candles in squeeze
- `in_long_trade` / `in_short_trade`: Trade state flags (removed for signal-only focus)

## Technical Implementation

### Strategy Structure

```go
type BBWidthEntryStrategyV2 struct {
    *v2.BaseStrategy
    
    // BB Width strategy specific parameters
    bbWidthThreshold   float64
    bbPeriod           int
    bbStdDev           float64
    squeezeDurationMin int
    squeezeDurationMax int
    
    // Strategy state (signal generation only)
    canGenerateLong  bool
    canGenerateShort bool
    
    // BB values and calculations
    bbUpper            float64
    bbLower            float64
    bbMiddle           float64
    currentBBWidth     float64
    lowestBBWidth      float64
    squeezeDetected    bool
    squeezeStartTime   *time.Time
    squeezeCandleCount int
    
    // BB width history tracking
    bbWidthHistory    []float64
    maxHistoryLength  int
    
    // Parameters manager for state persistence
    paramsManager *v2.StrategyParametersManager
}
```

### Key Methods

1. **Process()**: Main processing method implementing StrategyV2 interface
2. **validateBBData()**: Validates BB data integrity
3. **updateBBWidthHistory()**: Manages BB width history for lowest calculation
4. **getLowestBBWidth()**: Calculates lowest BB width from history
5. **checkSqueezeCondition()**: Detects and tracks squeeze conditions
6. **checkEntryConditions()**: Generates entry signals during squeeze
7. **Configure()**: Handles YAML-based configuration
8. **ResetState()**: Resets strategy state

### Signal Generation

#### Signal Structure:
```go
type EntrySignal struct {

    Timestamp time.Time              // Signal timestamp

}
```

#### Signal Metadata:
- `entry_type`: "bb_width_entry"
- `entry_time`: Time in HH:MM format
- `signal_purpose`: "data_tracking"
- `bb_upper`, `bb_lower`, `bb_middle`: BB band values
- `bb_width`: Current BB width
- `lowest_bb_width`: Lowest BB width in history
- `squeeze_duration`: Number of candles in squeeze
- `squeeze_start_time`: When squeeze started
- `squeeze_detected`: Whether squeeze is active
- `squeeze_candle_count`: Current squeeze candle count
