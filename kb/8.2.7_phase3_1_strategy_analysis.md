## Strategy Analysis

### 1. **1ST_ENTRY Strategy Analysis**

**File**: `python_strategies/mr_strategy/strategy/entry_strategies/first_entry.py`

#### **Core Logic**:
- **Purpose**: Immediate breakout detection from morning range
- **Entry Time**: After 9:15 AM (skips first candle)
- **Entry Type**: Immediate breakout with buffer

#### **Parameters Tracked**:

**Input Parameters**:
- `mr_high`: Morning range high value
- `mr_low`: Morning range low value
- `buffer_percentage`: 0.07% buffer for entry prices
- `candle.high`: Current candle high
- `candle.low`: Current candle low
- `candle.timestamp`: Current candle timestamp

**Calculated Parameters**:
- `mr_high_with_buffer`: MR high + 0.07% buffer
- `mr_low_with_buffer`: MR low - 0.07% buffer
- `in_long_trade`: Boolean flag for long position
- `in_short_trade`: Boolean flag for short position

**State Parameters**:
- `can_generate_long`: Boolean flag for long signal generation
- `can_generate_short`: Boolean flag for short signal generation

**Signal Parameters**:
- `signal.type`: IMMEDIATE_BREAKOUT
- `signal.direction`: LONG/SHORT
- `signal.price`: Entry price (with buffer)
- `signal.metadata.breakout_type`: 'immediate'
- `signal.metadata.entry_type`: '1st_entry'
- `signal.metadata.entry_time`: Timestamp in HH:MM format

### 2. **2_30_ENTRY Strategy Analysis**

**File**: `python_strategies/mr_strategy/strategy/entry_strategies/two_thirty_entry.py`

#### **Core Logic**:
- **Purpose**: Time-based entry at 2:30 PM
- **Entry Time**: 2:30 PM (configurable)
- **Entry Type**: Range-based entry with direction bias

#### **Parameters Tracked**:

**Input Parameters**:
- `entry_time`: 2:30 PM (configurable)
- `min_price_movement`: 0.1% minimum movement
- `candle.high`: Current candle high
- `candle.low`: Current candle low
- `candle.close`: Current candle close
- `candle.timestamp`: Current candle timestamp
- `direction`: BULLISH/BEARISH from config

**Calculated Parameters**:
- `range_high`: High at entry time (2:30 PM)
- `range_low`: Low at entry time (2:30 PM)
- `range_high_entry_price`: Range high + 0.03% buffer
- `range_low_entry_price`: Range low - 0.03% buffer

**State Parameters**:
- `in_long_trade`: Boolean flag for long position
- `in_short_trade`: Boolean flag for short position
- `can_generate_long`: Boolean flag for long signal generation
- `can_generate_short`: Boolean flag for short signal generation

**Signal Parameters**:
- `signal.type`: IMMEDIATE_BREAKOUT
- `signal.direction`: LONG/SHORT
- `signal.price`: Entry price (with buffer)
- `signal.range_values.range_high`: Range high at entry time
- `signal.range_values.range_low`: Range low at entry time
- `signal.range_values.range_high_entry_price`: Entry price for long
- `signal.range_values.range_low_entry_price`: Entry price for short
- `signal.metadata.entry_type`: '14:30' (entry time)
- `signal.metadata.entry_time`: '14:30' (entry time)

### 3. **BB_WIDTH_ENTRY Strategy Analysis**

**File**: `python_strategies/mr_strategy/strategy/entry_strategies/bb_width_entry.py`

#### **Core Logic**:
- **Purpose**: Bollinger Bands width-based entry
- **Entry Type**: Volatility squeeze detection and breakout

#### **Parameters Tracked**:

**Input Parameters**:
- `bb_width_threshold`: 20% default threshold
- `bb_period`: 20 period default
- `bb_std_dev`: 2.0 standard deviations default
- `squeeze_duration_min`: 3 candles minimum
- `squeeze_duration_max`: 5 candles maximum
- `candle.bb_upper_x`: Bollinger Bands upper
- `candle.bb_lower_x`: Bollinger Bands lower
- `candle.bb_middle_x`: Bollinger Bands middle
- `candle.timestamp`: Current candle timestamp

**Calculated Parameters**:
- `current_bb_width`: BB upper - BB lower
- `lowest_bb_width`: Historical lowest BB width
- `squeeze_detected`: Boolean flag for squeeze condition
- `squeeze_start_time`: Timestamp when squeeze started
- `squeeze_candle_count`: Number of candles in squeeze
- `bb_width_history`: Array of historical BB widths (max 50)

**State Parameters**:
- `in_long_trade`: Boolean flag for long position
- `in_short_trade`: Boolean flag for short position
- `can_generate_long`: Boolean flag for long signal generation
- `can_generate_short`: Boolean flag for short signal generation

**Signal Parameters**:
- `signal.type`: IMMEDIATE_BREAKOUT
- `signal.direction`: LONG/SHORT
- `signal.price`: Entry price
- `signal.metadata.entry_type`: 'bb_width_entry'
- `signal.metadata.squeeze_duration`: Number of candles in squeeze
- `signal.metadata.bb_width`: Current BB width
- `signal.metadata.lowest_bb_width`: Historical lowest BB width

### 4. **Morning Range Calculator Analysis**

**File**: `python_strategies/mr_strategy/strategy/morning_range.py`

#### **Core Logic**:
- **Purpose**: Calculate morning range values
- **Range Types**: 5MR (9:15-9:20) and 15MR (9:15-9:30)

#### **Parameters Tracked**:

**Input Parameters**:
- `range_type`: "5MR" or "15MR"
- `market_open`: 9:15 AM
- `candles`: DataFrame with OHLCV data

**Calculated Parameters**:
- `mr_high`: Highest high in morning range
- `mr_low`: Lowest low in morning range
- `mr_size`: Range size (high - low)
- `candle_count`: Number of candles in range
- `status`: 'success' or 'error'
- `message`: Error message if applicable

**Additional Calculations**:
- `atr_ratio`: Morning range size / ATR ratio
- `entry_prices`: Entry prices with buffer
- `trend`: Trend direction (BULLISH/BEARISH/NEUTRAL)

## Database Schema Design

### **Strategy Parameters Table**:

```sql
CREATE TABLE strategy_parameters_v2 (
    id BIGSERIAL PRIMARY KEY,
    stock_id VARCHAR(50) NOT NULL,
    strategy_name VARCHAR(50) NOT NULL,
    candle_timestamp TIMESTAMP NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    -- Common parameters
    in_long_trade BOOLEAN DEFAULT FALSE,
    in_short_trade BOOLEAN DEFAULT FALSE,
    can_generate_long BOOLEAN DEFAULT TRUE,
    can_generate_short BOOLEAN DEFAULT TRUE,
    
    -- 1ST_ENTRY parameters
    mr_high DECIMAL(10,2),
    mr_low DECIMAL(10,2),
    mr_high_with_buffer DECIMAL(10,2),
    mr_low_with_buffer DECIMAL(10,2),
    buffer_percentage DECIMAL(5,4),
    
    -- 2_30_ENTRY parameters
    entry_time TIME,
    range_high DECIMAL(10,2),
    range_low DECIMAL(10,2),
    range_high_entry_price DECIMAL(10,2),
    range_low_entry_price DECIMAL(10,2),
    direction VARCHAR(10),
    
    -- BB_WIDTH_ENTRY parameters
    bb_width_threshold DECIMAL(5,4),
    bb_period INTEGER,
    bb_std_dev DECIMAL(5,2),
    current_bb_width DECIMAL(10,2),
    lowest_bb_width DECIMAL(10,2),
    squeeze_detected BOOLEAN DEFAULT FALSE,
    squeeze_start_time TIMESTAMP,
    squeeze_candle_count INTEGER,
    bb_upper DECIMAL(10,2),
    bb_lower DECIMAL(10,2),
    bb_middle DECIMAL(10,2),
    
    -- Strategy state
    strategy_state JSONB,
    metadata JSONB,
    
    -- Indexes
    INDEX idx_stock_strategy_timestamp (stock_id, strategy_name, candle_timestamp),
    INDEX idx_strategy_timestamp (strategy_name, candle_timestamp)
);
```

## Conclusion

This analysis provides a comprehensive understanding of what parameters each Python strategy tracks. The key insights are:

1. **Common State Management**: All strategies share common state parameters (in_long_trade, in_short_trade, etc.)
2. **Strategy-Specific Parameters**: Each strategy has unique parameters that need to be tracked
3. **Real-time Processing**: All parameters need to be calculated and stored for each 5-minute candle
4. **State Persistence**: Strategy state must be maintained across candle processing

**Phase 3.1.1 is complete** and **Phase 3.1.2 is in progress**. The foundation infrastructure is being built to support parameter tracking and state persistence across candle processing.
